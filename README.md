# 木琴 注文会計アプリ(第1段階)の使い方

サーバー不要・月額ゼロ。`index.html` をタブレットやスマホのブラウザで開くだけで動きます。

## 置き方(どれか一つ)

1. **一番簡単**:`index.html` を端末に保存して、ブラウザで開く。ホーム画面に追加しておくとアプリのように使えます
2. **おすすめ(複数端末で使うなら)**:GitHub Pages に置く(予約フォームと同じやり方)。どの端末からも同じURLで開けます。売上データは「開いた端末のブラウザの中」にだけ保存され、ネットには出ません

> 注意:データはブラウザに保存されます。**毎日「締め」でCSVを保存する運用**にしてください(それが帳簿の原本になります)。ブラウザの履歴・サイトデータを消すと売上データも消えます。

## 毎日の流れ

1. **注文票を受け取ったら**:「＋新規伝票」→ 卓番号を入れて、紙と同じ並びの画面に数を打つ(マスをタップで+1、長押し/右クリックで−1)
2. **コース**は「コースの数」と「コースの蕎麦」の両方を入れる。合わない時は赤い注意が出ます
3. **缶ビールを入れると「お車の確認」の注意が出ます**
4. **会計**:「会計へ」→ 現金なら預かり金額をタップ(ちょうど/千円単位/五千/一万)→ お釣りが出る → 「会計完了」。QRは「QR決済」を選んで完了
5. **閉店後**:「締め」タブ → 釣銭準備金を入れ、レジの現金を金種カウンタで数える → 差額が出る → **「明細CSV」「日計CSV」を保存**

## 間違えたとき

- 会計済の伝票を開いて「会計取消」→ 未会計に戻って直せます
- 伝票ごと消すときは「伝票削除」

## 価格を変えたいとき

`index.html` の上の方にある「メニューマスタ」の数字を書き換えるだけです(品書き確定版 2026-10-20 の税込価格が入っています)。
